Instrument is any tradable financial object.



هر دارایی یا ابزار مالی که قابلیت قیمت‌گذاری، مشاهده یا معامله داشته باشد، یک Instrument است.



✓ هر Instrument دارای شناسه یکتا است.

✓ هر Instrument یک Type دارد.

✓ هر Instrument می‌تواند در Watchlist باشد.

✓ هر Instrument می‌تواند در Portfolio معامله شود.

✓ هر Instrument تاریخچه قیمت دارد.

✓ هر Instrument می‌تواند Corporate Action داشته باشد.

✓ سیستم باید بدون تغییر معماری، Typeهای جدید را پشتیبانی کند.

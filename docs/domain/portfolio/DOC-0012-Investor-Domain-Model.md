# DOC-0012 — Investor Domain Model

## Purpose

`Investor` is the ownership identity used by user-facing investment capabilities.
A persisted Portfolio will reference one Investor; Investor therefore becomes the first persistence prerequisite for Phase 5.

## Scope of this slice

The first end-to-end slice persists:

- `InvestorId` (ULID)
- `FullName`
- `CreatedOn`
- `IsActive`

Supported operations:

- Create
- Get by ID
- Get paged list
- Rename
- Activate
- Deactivate

No authentication/user-account binding is introduced in this slice. That concern remains separate from investment-domain ownership.

## Invariants

- Full name is required and trimmed.
- Investor identifiers are immutable.
- Activation/deactivation is idempotent.
- Investors are not deleted through the public API in this slice, preserving future portfolio ownership history.

## Portfolio relationship

The existing `Portfolio` domain prototype already references `InvestorId`.
After this Investor slice is persisted and verified, the next Phase 5 slice can persist Portfolio with a real FK to `Investors`, rather than an unenforced identifier.

## Persistence

Table: `Investors`

- `Id` varchar(26), primary key
- `FullName` nvarchar(200), required
- `CreatedOn`, required
- `IsActive`, required
- non-unique index on `FullName`

The migration must be generated by EF in the user environment and reviewed before database update.
